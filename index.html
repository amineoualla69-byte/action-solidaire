À propos de ce projet

Ce tableau de bord simule l'environnement de travail d'un Chef de projet Engagement Solidaire sur le périmètre IDF + Nord France dans le cadre du programme Action! de TotalEnergies.

Il couvre les quatre volets clés du poste : le pilotage des KPIs programme, la gestion des missions en vue Kanban, le réseau des associations partenaires, et l'animation des référents sur le territoire.

L'ensemble du code source, des données JSON, des templates COPIL et du plan de communication est disponible sur GitHub. Aucune dépendance externe — le dashboard fonctionne directement dans le navigateur.
